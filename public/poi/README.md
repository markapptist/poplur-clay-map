# Clay POI category icons

Drop transparent PNGs here named `clay_<maki>.png` and the map picks them up
automatically (missing files are skipped). Wired categories:

clay_fast-food.png   — burger        clay_cafe.png     — coffee cup
clay_restaurant.png  — plate/fork    clay_grocery.png  — cart/basket
clay_bar.png         — glass         clay_fuel.png     — pump
clay_bank.png        — coin          clay_clothing-store.png — shirt

Category icons, not brand logos (trademark-safe) — the POI label underneath
already shows the venue's real name. ~256px transparent PNGs of your clay
models photograph best.
